==================================================
NOTES FOR VERSION 1.0.0
=======================

This release is a front-end/demo template.

The authentication and account management features currently
use browser-side JavaScript and LocalStorage.

This release does not include:

* Production backend.
* Server-side authentication.
* Database server.
* API server.
* Secure password hashing.
* Production-grade access control.

2.0.0 - AN consent-based security lab
- Replaced automatic invasive collection with explicit consent-based session diagnostics.
- GPS is requested only after a separate user action and browser permission.
- Added AN shortcut to Master dashboard.
- Added responsive visual refinements to the landing page.
- Reminder: LocalStorage is browser-local; remote multi-user monitoring requires a backend, authentication, access controls and retention policy.
